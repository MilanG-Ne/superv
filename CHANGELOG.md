# Changelog

## 1.0.0 (2026-09-30)

First release.

- Super+V panel with clipboard history: text, rich text (HTML/RTF), images and copied files.
- Click or press Enter to paste into the app you were using; terminals get Ctrl+Shift+V.
- Pin items; pinned items survive a reboot, the rest is cleared, like Windows.
- **⋯** menu: paste, paste as plain text, copy without pasting, pin, delete. "Clear all" keeps pinned items.
- Search the history by typing.
- Emoji (Super+.), kaomoji and symbols tabs with recently used items.
- Keeps the clipboard when the app you copied from closes.
- Ignores passwords that password managers mark as secret.
- Settings window modelled on Windows' clipboard settings; optional tray icon.
- Xfce shortcuts set up automatically; `.deb` package and a no-root install script.
